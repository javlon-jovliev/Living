# Living — tushunchalar lug‘ati

**Holat:** Working definitions; texnik spetsifikatsiya emas.

| Atama | Ishchi ta'rif |
|---|---|
| **Living** | Foydalanuvchi o‘z hisoblash muhitini bevosita shakllantira olishi haqidagi tadqiqot loyihasi. |
| **Personal Space** | Bir foydalanuvchiga tegishli, vaqt davomida saqlanadigan obyektlar makoni. |
| **Living Object** | Identifikatori, ko‘rinishi, ma'lumoti, holati, xatti-harakati va ruxsat chegaralari bo‘lgan birlik. |
| **Shape** | Obyektning vizual va geometrik ifodasi; mazmunning o‘zi emas. |
| **State** | Obyektning ma'lum paytdagi holati. |
| **Data** | Obyekt saqlaydigan yoki unga bog‘langan ma'lumot. |
| **Behavior** | Obyekt bajarishi mumkin bo‘lgan hisoblash va interaksiya qoidalari. |
| **Capability** | Aniq imkoniyat yoki resursga chegaralangan kirish huquqi. |
| **Permission** | Foydalanuvchi yoki tizim tomonidan berilgan amal ruxsati. |
| **Composition** | Bir nechta obyektning funksional/semantik jihatdan birlashishi. |
| **Semantic composition** | Birlashtirish natijasida texnik ulanishdan tashqari foydali ma'no va xatti-harakat hosil bo‘lishi. |
| **Direct manipulation** | Grafik obyektni ishning o‘zida bevosita boshqarish va tahrirlash. |
| **Malleable computing** | Hisoblash muhitini foydalanish jarayonida qayta shakllantirish g‘oyasi. |
| **Scene graph** | Obyektlarning fazoviy/ko‘rinish munosabatlari grafigi; semantik modelning o‘rnini bosmaydi. |
| **Object graph** | Obyektlarning identifikatori, munosabatlari, imkoniyatlari va tarixini ifodalovchi model. |
| **Typed interface** | Input/output va imkoniyatlarning tekshiriladigan turlari. |
| **Behavior runtime** | Obyekt funksiyasini xavfsiz bajaradigan dasturiy qatlam. |
| **Sandbox** | Kod va amallarni cheklangan muhitda bajarish usuli. |
| **Provenance / lineage** | Yangi obyekt qaysi manba va transformatsiyalardan hosil bo‘lganining tarixi. |
| **Reversibility** | O‘zgarishni bekor qilish yoki avvalgi holatga qaytish xususiyati. |
| **Local-first** | Asosiy ish va ma'lumotlarga kirishning offline holatda ham ishlashi. |
| **CRDT** | Turli nusxalardagi bir vaqtli tahrirlarni moslashtirish uchun ma'lumot tuzilmalari oilasi. |
| **OS-level** | Tizim xizmatlari va desktop shell/runtime bilan chuqur integratsiya; albatta yangi kernel emas. |
| **Living-native** | Maxsus Living obyekt modeli orqali boshqariladigan komponent. |
| **External app object** | Integratsiya orqali ko‘rsatiladigan, ichki imkoniyatlari API bilan chegaralangan tashqi dastur. |

Atamalar dastlabki. Yangi tadqiqot chiqqanda qayta ko‘rib chiqiladi; noaniq terminlar misollar va qarshi misollar bilan aniqlashtiriladi.
